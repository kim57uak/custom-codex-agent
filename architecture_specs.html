Agent Orchestrator Desktop

Multi-Agent Orchestration & Visualization Desktop App

기술 스택 (Tech Stack)

Frontend / Renderer

  • React 18
  • TypeScript
  • Vite
  • Zustand

Backend / Main Process

  • Electron
  • Node.js
  • SQLite
  • Codex / Gemini CLI

주요 구현 기능 (Key Features)

  • Multi-Agent Orchestration: 에이전트 계층구조 시각화, 실시간 상태 모니터링, 워크플로우 엔진 기반의 순차/병렬 에이전트 실행 기능.
  • Desktop Native: 시스템 트레이 백그라운드 구동, 네이티브 알림, 자동 업데이트 (electron-updater), 오프라인 모드 지원.
  • IDE-style Layout: Activity Bar, Sidebar, Main Area, Terminal Panel로 구성된 VS Code / Cursor 스타일의 전문적인 UI/UX 적용.
  • Skill & Agent Inspector: Monaco Editor가 통합된 설정 파일(SKILL.md, config.json) 브라우징 및 실시간 파일 감시 기능 탑재.
